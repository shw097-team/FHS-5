# 07｜APIs／Functions／Producers／Consumers

### 整合註記 07.A｜preflight/freeze/verify 與八欄 Finding

`preflight → freeze → map_claims → request_original_run → verify_observation → compare_and_report` 為候選責任；Finding 原八欄 `{id, severity, class, subject_sha, command, exit, raw_sha256, reproduction}` 不塞概念詞。

### Functions／Producers／Consumers 的受界算法

1. **preflight(source,request)**：Host綁受權ReadRoot/ReportRoot，拒`..`/跨根/UNC逃逸/symlink或junction/重複JSON鍵/超限，先核5pin與Source/Scope；回IdentityView或typed拒碼，不做業務判定。
2. **freeze(candidate_context)**：核HEAD與實際Candidate bytes、CaseSet/Oracle/Evidence；固定Receipt時間與Host/Epoch。任何pin改變使舊observations受影失效，先停比對不盲retry。
3. **map_claims(claims,original_trace)**：逐Clause/Child/POS/NEG/Exception/Case建立關係，缺Reader保null/UNBOUND，原Expected/Oracle不能由Maker覆寫。
4. **request_original_run(case_refs,frozen,admission_ref)**：送原Owner受限request；原Runner核Admission/Fixture/rollback，回真argv/exit/raw。`OriginalCaseRunner.invoke(...)`只是原Owner待綁介面描述，**不是本輪發現的可呼叫API**。
5. **verify_observation(receipt,raw)**：原EvidenceReader核binarySHA/Principal/trust chain/Scope/Host/Epoch/Case/Oracle/RawSHA，必要fresh replay；驗不過不REPRODUCED。
6. **compare_and_report(expected,observed)**：原Oracle比對POS與反例，回Findings/NotCovered/五值advisory；FAR讀真frozen refs，原Checker另判。

以上為可施工的候選函式責任，不是新增Canonical callable。原Runner/receipt契約在〔S12:e563f6c4a2ab28d70ea71a7877a9abc6dd2d570d145631a47e3a59671ba690a8:L970–L980〕。

**receipt最小承載**：runner_id/binary_sha256/host_id/os_principal/policy_epoch/operation_id；OriginalCase/CaseSet/Oracle/Source/Candidate/Evidence hashes；subject/scope/fuo；command_argv/exit_code；stdout/stderr/world raw ref+SHA；started/ended/monotonic_run_id；independent_actor/signature_envelope/verification_method/replay/redacted_export_ref。每欄原信任鏈驗證後才可承證，不因字串填滿即合格。

**Finding八欄（原字面）**：`{id, severity, class, subject_sha, command, exit, raw_sha256, reproduction}`。`subject_sha` 指被挑戰凍結候選；command 是真 argv、exit 是原執行整數、raw_sha256 指真原輸出，reproduction 只 `REPRODUCED/UNREPRODUCED`。S12 Report Schema `required[]` 同八鍵；`original_case_id/first_fail/advisory_only` 是該 schema 另列可選欄，不用 Expected/Observed 等概念詞替原八鍵。Expected/Observed/Clause/Oracle/Impact/NextOwner 在 trace/evidence/隔離分析側車保存，strict schema 沒列的鍵不得硬塞。〔S12:e563f6c4a2ab28d70ea71a7877a9abc6dd2d570d145631a47e3a59671ba690a8:L496–L566〕

原 Skill `Output shape`（實際只讀定位與 hash 見附錄 E2）還含 `verdict/findings[]/not_covered[]/claim_ceiling_recommendation`；報告 original_checker_verdict=null。僅概念解說或八欄齊全不能證 command 真跑，仍要原 EvidenceReader/Runner 驗章；沒有原 Raw 就不捏造 exit/raw_sha。

**Privacy**：原Raw與mask digest分帳，僅最小ref/hash/遮罩片段輸出；PUBLIC_METADATA/INTERNAL_SOURCE/RESTRICTED_LOG/PROTECTED_ORIGINAL_RECEIPT按原Custodian ACL，保留期未知不造固定天數；不向網路上傳原Raw。POS：同Case真Raw可回查；NEG：只有command字串與exit0沒有raw/World，UNREPRODUCED而非OriginalPASS。
